Sponsor HatchZip

HatchZip is free and open source, and it stays that way. Sponsorship pays for the time to maintain it and for the parts that cost money.

HatchZip extracts ZIP, 7z, RAR and tar archives in place: it frees the archive's space as the files come out, so a 100 GB archive needs room for about 100 GB of files, not 200 GB. It checks that the extraction fits before it changes anything, and resumes after a crash. It is built by Yash Bavadiya, a computer science student at IIT Jodhpur, with contributions from the community.

What sponsorship pays for

  • Maintenance time. Reviewing contributors' pull requests, fixing bugs and making releases. Every change that touches how the archive is freed gets crash tests on Linux, macOS and Windows.
  • macOS signing. The Apple Developer Program costs 99 USD a year. With it, the macOS app is signed and notarized and opens without a warning. Windows signing is provided free by the SignPath Foundation.
  • More formats. .tar.bz2 is in progress; .tar.zst and native split ZIP (.z01) are next.
  • A security review. HatchZip deletes archive bytes as it goes, so the code that decides what is safe to free deserves an independent review.

For companies

HatchZip's engine is a Rust library, hatchzip-core, so in-place extraction can go into a game launcher, mod manager, installer, updater, NAS app or data pipeline: anywhere people unpack large archives on disks that are nearly full.

  • Sponsorship. Through GitHub Sponsors. Company sponsors get their logo in the README and on this page.
  • Feature sponsorship. Fund a specific format or platform feature, with an agreed scope and date. It ships in the open-source project for everyone.
  • Integration support. Help embedding hatchzip-core in your product, and support with agreed response times.

Sponsors don't get private builds or a vote on safety checks: HatchZip refuses whatever could lose data, for everyone.
